# تحديثات الموقع — Gold Edition

## الألوان والستايل
- اتغير الثيم بالكامل من الأزرق/السماوي (cyan) لثيم ذهبي/أسود فخم (gold on near-black) مستوحى من صورة الديسكورد بتاعتك.
- خط جديد: **Playfair Display** للعناوين (خط سيريف فخم) + **Inter** للنصوص العادية، بدل الخط الافتراضي.
- كل الـ glow effects والـ particles اتلونت ذهبي بدل سماوي.

## البانر والأفتار
- الـ GIFs اللي بعتهالي كانت تقيلة جدًا (7MB و 6.4MB)، فحولتهم لـ **MP4** مضغوط بنفس الشكل بالظبط لكن بحجم أصغر بكتير (~460KB و ~670KB) — ده مهم جدًا عشان سرعة تحميل الموقع، خصوصًا على الموبايل.
- البانر (`banner.mp4`) شغال autoplay + loop فوق الكارد.
- الأفتار (`avatar.mp4`) جوه فريم دائري بحلقة ذهبية بتلمع حواليه (زي التاج في الصورة).
- لو حابب تفضل GIF فعلي بدل MP4 قولّي وأرجعلهم، بس الأداء هيبقى أبطأ.

## عداد الزوار 👁️
- ضفت badge تحت الكارد الرئيسي بعلامة عين وعدد الزوار، بيزيد تلقائي كل ما حد يفتح الموقع (مربوط بـ API مجاني بدون تسجيل: countapi.mileshilliard.com).

## تحسينات SEO / بروفيشنال
- Title و description محسّنين للموقع بدل "Generated by create next app".
- Open Graph + Twitter Card image عشان لما حد يشير اللينك في تويتر/واتساب يطلعله preview حلو.
- Favicon اتحط من صورة الأفتار.
- theme-color للمتصفح على الموبايل.
- `prefers-reduced-motion` مدعوم (لو حد فعّل تقليل الحركة من إعدادات جهازه).
- Focus states واضحة للـ accessibility.

# تحديثات الموقع — Gold Edition v2

## تحديث جديد: Light Mode شغال فعلي
كان فيه مشكلة إن "Light Mode" في الكود الأصلي بيبدّل بين درجتين من نفس اللون الغامق (مكنش فيه فرق حقيقي). دلوقتي:
- عملت نظام ألوان كامل بـ CSS variables، فيه نسخة "dark" (أسود دافي + ذهبي فاتح) ونسخة "light" (كريمي/عاجي دافي + ذهبي غامق للتباين).
- كل الكروت، الخلفيات، الحدود، والنصوص بقت تستجيب فعليًا لما تدوس على زرار الشمس/القمر.
- الـ GitHub Calendar كمان بقى عنده ثيم فاتح وغامق منفصلين.

## تحديث جديد: AI Assistant شغال فعلي ومجاني بالكامل
الـ AI Assistant بقى شات حقيقي بيرد عليك، مش placeholder. اتعمل:
- `app/api/chat/route.ts` — route بيكلم **Groq** (مش Anthropic، لأن الـ Anthropic API مالوش باقة مجانية دايمة). Groq بيدّيك مفتاح مجاني بالكامل من غير كارت ائتمان، وسريع جدًا (بيشغّل موديل Llama 3.3 70B).
- واجهة شات كاملة (رسائل، تحميل، إرسال بالـ Enter).

### عشان يشتغل لازم:
1. روح على https://console.groq.com/keys وسجّل دخول بإيميلك بس (من غير كارت ائتمان).
2. اعمل API key جديد.
3. اعمل نسخة من ملف `.env.local.example` باسم `.env.local`.
4. حط الـ key بتاعك مكان `gsk_xxxxx...`
5. `.env.local` متجاهل من git تلقائيًا (موجود في `.gitignore`) — الـ key مش هيترفع لحد.
6. لو بتنشر على Vercel، ضيف نفس الـ variable (`GROQ_API_KEY`) من Project Settings → Environment Variables.

**الحد المجاني عند Groq** كويس جدًا لموقع شخصي (تقريبًا 1000 طلب في اليوم)، فمش هتحتاج تدفع حاجة أبدًا في الاستخدام العادي.
